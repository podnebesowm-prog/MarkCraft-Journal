#Installation

1. Go to the **Releases** section on the right side of this page.
2. Download the latest archive (`MarkCraftJournal_1.0_Official.zip`).
3. Unzip the archive into any convenient folder.
4. Run the `MarkCraftJournal.exe` file.



About the Program

**MarkCraft Journal** is your personal digital diary.
*   Homework list (add, mark as done, delete).
*   Automatic cloud synchronization (Firebase).
*   Offline mode (works without internet).
*   Personalized greeting by name.
*   Clear completed tasks button.
